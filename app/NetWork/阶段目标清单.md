## 阶段 2：MQTT 连通

**目标**：两个终端连同一个 broker、同一个房间，互相收到消息。

**交付物**

| 文件 | 作用 |
| --- | --- |
| `NetWork/NetOptions.cs` | 解析 `--host / --join / --ping / --broker / --room / --name` |
| `NetWork/MqttTransport.cs` | 连接 / 订阅 / 发布 / 收件箱 / `IsConnected` / `Log` |
| `NetWork/NetHost.cs` | 生命周期与三种模式分派 |

**任务**

- [x] 连接 broker（`WithTcpServer`）
- [x] 订阅 `snake/{room}/#`
- [x] 发布 `snake/{room}/hello`
- [x] Ping 模式能收发自己的消息
- [x] 参数缺值 / 未知参数有提示，不崩

**验收**

`dotnet run -- --ping --room t1 --broker broker.emqx.io:1883` 能看到 `[mqtt]已连接`、`[mqtt] 订阅`、`[recv]`。

**常用命令**

    dotnet run -- --host --room snake-abc123 --broker broker.emqx.io:1883
    dotnet run -- --join --room snake-abc123 --broker broker.emqx.io:1883 --name 张三

## 阶段 3：只读观战

**目标**：Host 跑真实游戏并广播快照，Client 只收不发、把画面画出来。

    Host:   GameWorld.Snapshot() -> ProtoCodec.ToProto() -> SnapshotPump(100ms) -> MQTT
    Client: MQTT -> GameState.Parser.ParseFrom() -> RemoteRender.Draw() -> ProtoCodec.FromProto() -> MapPrinter

**任务**

- [x] `ProtoCodec.ToProto`：填 `Width / Height / RemainingSeconds`
- [x] `ProtoCodec.ToProto`：修正方向枚举映射（不是强转）
- [x] `ProtoCodec.FromProto`：网络消息还原成 `WorldSnapShot`
- [x] `SnapshotPump`：独立定时器每 100ms 发布；`Dispose` 真正取消
- [x] `NetHost.Attach`：幂等挂载，Host 才算
- [x] Host 分支不阻塞，进游戏后由 `Attach` 启动广播
- [x] Client 分支：只处理 `/state` 主题，解析后交给 `RemoteRender`
- [x] `RemoteRender` 复用 `MapPrinter`，不再自己画一套
- [x] 本机渲染与观战渲染共用 `MapPrinter`
- [ ] 双终端联调：Host 玩一局，观战端 100ms 刷新
- [ ] 客户端 `Esc` 退出（现在 `Drain` 里的 `return` 只退出方法）

**验收**

Host 终端正常游戏；观战端棋盘跟着变、分数同步、结束时显示「对局结束」。
